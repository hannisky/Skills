# Jardin Garden Plan (Zone 4 Scandinavia)

This folder contains the first-pass plan, layout sketch, crop plan, and activity timeline.
Date of plan: 2026-03-13
Location climate: Zone 4 (northern Scandinavia)

## Files
- README.md: This overview.
- layout.md: Top-down layout sketch and bed assignments.
- layout.svg: Scaled top-down diagram (visual).
- crops.md: Crop list, varieties to consider, and crop-specific notes.
- calendar-2026.md: Week-by-week timeline from now through autumn.
- tasks.md: Action checklist by phase.
- rotation-notes.md: Rotation guidance and 2–3 year horizon notes.
- observations.md: Log for notes, issues, and change requests.

## How to use
1. Start with layout.md to confirm the bed map.
2. Use calendar-2026.md for timing and reminders.
3. Track progress and issues in observations.md.
4. Update rotation-notes.md after harvest.
